# Visual reference sheet

Reference only; do not ship this art with our games.

## Official PBS KIDS feature art

![Sesame Street Dress Up Time feature art](https://image.pbskids.org/pbs-kids-infra/global/Property-Assets/SESA-Sesame-Street/Game-Cards/SESA-DressUpTime-FeatureGraphic-Summer.jpg?resize=300x)

The feature art shows Elmo and Abby in visibly layered costumes, which is useful as a reminder that outfit state must be rendered on the character rather than exposed as text.

The official game page is https://pbskids.org/games/play/dress-up-time/8573 and PBS KIDS for Parents describes the task as choosing clothing pieces to complete outfits Elmo and Abby want to wear.
