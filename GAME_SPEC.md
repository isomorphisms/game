# Cheetah game spec

This file records only rules already stated by the game designer. Open questions stay open rather than being turned into mechanics.

## Settled rules

- The player is a cheetah.
- The cheetah runs.
- The player has to collect all the food.
- Bombs have to be avoided.
- Collecting all the food earns one star.
- The game has three levels to win.

## Unanswered questions

- Does the cheetah run automatically, or does the player control every movement?
- What kinds of food are in the game?
- What happens when the cheetah touches a bomb?
- What makes the three levels different?

## Smallest first playable

Make one playable level that contains only the settled core: a running cheetah, food that can all be collected, bombs that can be avoided, and a one-star result when all food is collected. Do not decide the movement scheme, bomb consequence, food types, or differences between levels until the game designer answers those questions. The other two levels can follow after this core is playable.
